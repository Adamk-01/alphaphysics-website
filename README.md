# ALPHAPHYSICS EDU CONSULT website
Run: `npm install` then `npm run dev` (http://localhost:3000). Production: `npm run build && npm start`.
Edit business info, group link, socials, services: `lib/site.ts`. Articles: `lib/posts.ts`. Logo: `public/logo.jpg`. Flyer: `public/2027-flyer.png`.
Env: copy `.env.example` to `.env.local` and set NEXT_PUBLIC_SITE_URL.
